# 多元互動學習探索中心 (Multi-Subject Interactive Learning Portal)

跨領域沉浸式數位互動學習平台 · 經典人文 ✕ 運動科學

## 📖 專案簡介
本專案整合「**國文學科經典**」與「**體育運動技能**」兩大主題，運用動態分鏡動畫、Tone.js 聲光音效、互動物理模擬實驗室、註解精讀、心靈圖譜與即時動作診斷，打造兼具人文底蘊與運動科學的一站式數位自主探索平台。

## 📂 檔案結構
- `index.html`：**多元主題入口首頁（Portal & Exploration Hub）**，整合國文與排球兩大專題入口、亮點導覽與直達子模組卡片。
- `beiying.html`：**國文學科專題 · 朱自清《背影》互動文學探索平台**（包含 4 步驟買橘動態分鏡、原文畫線筆記、作者 IG 社交主頁、父子情感圖譜、真實歷史考證與問答測驗）。
- `voll.html`：**體育運動專題 · 排球接發球技術講堂**（包含準備姿勢與預判、手臂夾角與插切壓技巧、互動模擬接球實驗室、實戰訓練菜單與問題診斷測驗）。
- `package.json`：專案設定與本地伺服器啟動腳本。

## 🚀 快速開始
1. **直接開啟**：在瀏覽器中直接開啟 `index.html`。
2. **本地伺服器啟動**：
   ```bash
   npx serve .
   ```
   或
   ```bash
   npm start
   ```

## ✨ 兩大核心專題與模組

### 📘 國文學科專題：朱自清《背影》
1. 🚄 **經典重現·買橘**：動態分鏡拆解父親攀爬月台的四個步驟（探、穿、攀、縮、傾）。
2. 🖋️ **原文經典精讀**：動詞、色彩對比、修辭與象徵即時解析。
3. 📱 **朱自清 IG 主頁**：以現代社群介面呈現作家生平與經典散文。
4. 💓 **父子情感圖譜**：呈現作者從年少自傲到體會父愛的心境覺醒。
5. 📜 **真實歷史與和解**：記錄 1917 家境變故與 1928 年父子冰釋前嫌。
6. 🎯 **深度問答測驗**：文學理解即時評量與詳解。

---

### 🏐 體育專題：排球接發球技術講堂
1. 🥋 **準備姿勢與動態預判**：雙腳站距、重心前傾、分腿墊步（Split-step）與視線追蹤。
2. 👐 **手臂夾角與擊球平面**：「插、切、壓」三字訣，手腕鎖定與借力卸力。
3. 🎮 **互動模擬接球實驗室**：參數化模擬接球角度、來球力道與到位率軌跡。
4. ⏱️ **實戰訓練菜單**：單人對牆、雙人拋接與高速發球對抗等階梯訓練。
5. 🩺 **動作診斷與測驗**：常見錯誤診斷與核心觀念互動評量。
