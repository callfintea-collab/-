# 多元互動探索與競技訓練平台 · 總專案中心

本專案匯集體育競技實戰、戰術沙盤與文學全景互動體驗，純前端打造，免安裝即開即用。

---

## 📂 專案檔案架構與入口

| 檔案名稱 | 模組主題 | 特色與互動機制 |
| :--- | :--- | :--- |
| **[`index.html`](index.html)** | 🌐 **全站總入口門戶** | 一站式導覽卡片、專題快速傳送門與系統概覽 |
| **[`badminton.html`](badminton.html)** | 🏸 **羽球接發球大師** | 2.5D 透視發球反應遊戲、6大回擊決策鍵、戰術沙盤與 BWF 規則 |
| **[`voll.html`](voll.html)** | 🏐 **排球接發球講堂** | 頂級到位率技術拆解、手臂角度、互動接球模擬實驗室與自我診斷 |
| **[`beiying.html`](beiying.html)** | 📖 **朱自清《背影》探索** | 1917 浦口買橘分鏡、作者現代 IG 主頁、原文精讀賞析與情感圖譜 |

## 🚀 快速啟動

1. **直接開啟**：在瀏覽器中雙擊開啟 `index.html` 即可進入總入口首頁。
2. **本地伺服器**：
   ```bash
   npx serve .
   ```
   或
   ```bash
   npm start
   ```
